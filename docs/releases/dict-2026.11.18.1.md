# 词典包 dict-2026.11.18.1 发布说明

## 主要变更

首批可下载词典包，与 app 内置的核心词典并集使用：

- 数据来自 ECDICT，固定在提交 `9c46923`（2026-10-20）。每条只归入一个包；同时属于两个学科的词条两包各放一份，查词时去重。
- 核心词典（内置）收录常用词（带考试标签、柯林斯或牛津标记，或 BNC/词频前 6 万）、它们的全部变形和由常用词组成的通用短语（含短语动词、习语），以及变形 → 原形表。
- 扩展词汇：其余普通单词和短语，多为生僻词。
- 八个学科包：只收全部义项都带对应学科标注（如“[医]”）的词条。
- 人名地名：首字母大写的单词和短语。
- 每条保留全部中文义项、英文释义（硬换行已接回）、考试标签、柯林斯星级、牛津 3000 标记和词形变化。

`dict-2026.11.18` 因 CI 找不到 Python 3.9 在校验阶段失败，没有发布任何词典包；本版内容与它相同，只是版本号不同。

## 上线

推送 tag 后，Actions 从上面固定的数据源重新构建全部词典包，核对其中的核心词典与 app 内置的一致，
再创建 Release，附上各词典包、manifest.json 和 SHA256SUMS。Release 不会成为仓库的 Latest Release。

发布成功后运行 `python3 Tools/dictionary_release.py adopt 2026.11.18.1`，提交并推送
`Dictionaries/manifest.json`，app 的“设置 › 词典”才会列出这批词典包。
